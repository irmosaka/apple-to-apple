# اپل‌تو‌اپل (Apple to Apple)

مقایسه محصول به محصول — نسخه ساده و آماده برای GitHub Pages

## ویژگی‌ها

- مقایسه دو محصول کنار هم با جدول ویژگی‌ها
- تشخیص خودکار برتری عددی (سبز/قرمز)
- داشبورد مدیریت برای افزودن / ویرایش / حذف محصول
- امکان اضافه و کم کردن ویژگی‌ها برای هر محصول
- پشتیبانی از لینک دیجی‌کالا (نمایش لینک)
- Export / Import فایل JSON برای ذخیره دائمی روی گیت‌هاب
- کاملاً فارسی و راست‌چین
- بدون نیاز به سرور یا دیتابیس

## نحوه استفاده

### ۱. کلون یا دانلود ریپو

```bash
git clone https://github.com/irmosaka/apple-to-apple.git
cd apple-to-apple
```

### ۲. اجرای محلی (اختیاری)

چون از `fetch` برای خواندن JSON استفاده می‌شود، بهتر است با یک سرور ساده اجرا کنید:

```bash
# با Python
python -m http.server 8000

# یا با VS Code Live Server
```

سپس برو به `http://localhost:8000`

### ۳. استقرار روی GitHub Pages

1. برو به Settings → Pages
2. Source را روی `Deploy from a branch` بگذار و branch را `main` انتخاب کن
3. چند دقیقه صبر کن تا سایت بالا بیاید

آدرس نهایی:
`https://irmosaka.github.io/apple-to-apple/`

## مدیریت محصولات

1. برو به صفحه **داشبورد مدیریت**
2. محصول جدید اضافه کن یا موجودی را ویرایش کن
3. ویژگی‌ها را با دکمه «+ افزودن ویژگی» کم و زیاد کن
4. بعد از ذخیره، روی **Export فایل JSON** کلیک کن
5. فایل دانلود شده را جایگزین `data/products.json` در ریپو کن و push کن

> تغییرات فقط در مرورگر شما (localStorage) ذخیره می‌شوند. برای دائمی شدن حتماً Export و جایگزین کردن فایل لازم است.

## محدودیت اسکرپ دیجی‌کالا

به خاطر سیاست CORS مرورگرها، نمی‌توان مستقیم از سمت کلاینت اطلاعات محصول را از دیجی‌کالا گرفت.  
در نسخه فعلی لینک را نگه می‌دارد و شما مشخصات را دستی وارد می‌کنید.

اگر بخواهی اسکرپ خودکار داشته باشی، می‌توانی از این راه‌ها استفاده کنی:

- یک Cloudflare Worker یا Vercel Serverless به عنوان پروکسی
- یا نسخه بعدی فول‌استک با Next.js
