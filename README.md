# اپل‌تو‌اپل (Apple to Apple)

مقایسه محصول به محصول — نسخه ساده و آماده برای GitHub Pages

## ویژگی‌ها

- **مقایسه چندرقیبی**: یک محصول خودت رو همزمان با چند رقیب مقایسه کن
- **دسته‌بندی (Category)**: محصولات بر اساس دسته فیلتر و گروه‌بندی می‌شوند
- تشخیص خودکار برتری عددی (سبز/قرمز)
- داشبورد مدیریت کامل (افزودن / ویرایش / حذف)
- امکان اضافه و کم کردن ویژگی‌ها
- لینک کردن چند رقیب به هر محصول خودت
- پشتیبانی از لینک دیجی‌کالا
- Export / Import فایل JSON برای ذخیره دائمی روی گیت‌هاب
- کاملاً فارسی و راست‌چین
- بدون نیاز به سرور یا دیتابیس

## نحوه استفاده

### ۱. کلون ریپو

```bash
git clone https://github.com/irmosaka/apple-to-apple.git
cd apple-to-apple
```

### ۲. اجرای محلی

```bash
python -m http.server 8000
```

سپس برو به `http://localhost:8000`

### ۳. استقرار روی GitHub Pages

1. Settings → Pages → Source: Deploy from a branch → `main`
2. آدرس نهایی: `https://irmosaka.github.io/apple-to-apple/`

## مدیریت محصولات

1. برو به **داشبورد مدیریت**
2. محصول جدید اضافه کن (نوع: محصول من یا رقیب)
3. دسته را انتخاب یا بساز
4. برای «محصول من» می‌تونی چند رقیب لینک کنی
5. ویژگی‌ها را کم و زیاد کن
6. بعد از ذخیره → **Export فایل JSON** → جایگزین `data/products.json` در ریپو
